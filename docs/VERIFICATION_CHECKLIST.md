Reproduce:

```bash
source /workspace/.cloud-tools/activate.sh
cloud_gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
bash firmware/tests/run_host_tests.sh
export PYTHONPATH=/workspace/.cloud-tools/arduino/python-deps
export XDG_CACHE_HOME=/workspace/.cloud-tools/arduino/cache
/workspace/.cloud-tools/arduino/arduino-cli --config-file /workspace/.cloud-tools/arduino/arduino-cli.yaml compile \
  --fqbn esp32:esp32:esp32:FlashMode=dio --jobs 4 firmware/SmartDryingRack
```

Outside this cloud workspace, set `ARDUINOJSON_SRC` to the installed ArduinoJson 7.4.2 `src` directory for host tests. See [firmware setup](ESP32_FIRMWARE.md).
